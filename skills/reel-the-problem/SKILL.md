# REEL THE PROBLEM — the attention harness

## WHERE THIS COMES FROM (the source lesson, so the transfer is honest)

An LLM cannot watch video. The video system solved comprehension by making **REELS**:
contact sheets that convert the unreadable stream into an **addressed grid** — every cell
stamped with its timecode + absolute frame — read in **three passes, wide to tight**
(`everything` → `one-thing` → `still`), under one hard law: **never conclude anything the
current resolution cannot discriminate; get the still instead of narrating a plausible
impression.** Comprehension arrived not from a smarter model but from a readable
representation plus a discipline for reading it.

The transfer: a hard reasoning problem is ALSO an object you are effectively blind to at a
glance. The glance-answer (fluent, coherent, often wrong) is the "narrated plausible
impression" — the completion trap. The fix is the same fix.

## THE SYSTEM — six moves, in order (the reel loop)

### 1. REEL — convert the problem into an addressed readout
Before any reasoning: rewrite the object as a grid/table/list where **every part has a
stable address** (cell (2,3) · premise P2 · line 47 · term t₄). Nothing stays in the
"stream" of working memory. A claim that cannot cite an address is not yet a claim.
- IQ matrix → address all 9 cells; sequence → index every term; word problem → number
  every given; code bug → line-addressed trace.
- Utility: addresses make every later step checkable and every error localizable.

### 2. SWEEP — pass 1 over the WHOLE reel, low resolution
Walk every address once and note what each contains — briefly, but **exhaustively**. The
sweep's job is to surface the suspect you were NOT looking for. Two prohibitions, verbatim
from the source law: **do not skip the sweep and start drilling a guessed cell** (guessing
which part matters is how the real feature ships past you), and **do not stop at the sweep
and report** (sweep findings are unconfirmed).

### 3. DRILL — every suspect at full resolution
For each cell/feature the sweep flagged: pull the still. Extract its features explicitly —
counts, shapes, positions, deltas, types — written down, not held. **THE RESOLUTION LAW:
if the current representation cannot discriminate a detail, say so and raise the
resolution (re-read, re-derive, expand the cell); never narrate what it "probably" is.**
This single clause is most of the IQ delta: the default fails by answering below
resolution.

### 4. MEASURE — pin every impression with an explicit feature
Watching FINDS, measuring PROVES. An impression ("the shapes seem to rotate") becomes a
measurement ("cell(1,1)→(1,2): +90°; (1,2)→(1,3): +90°; row 2: +90°,+90°") before it may
be used. And **verify the instrument**: ask of every check you're using, "can this pass
while the answer is wrong?" A check satisfiable by decoration (a rule that fits the cells
you happened to test) is measuring nothing — the source system shipped three quietly-wrong
instruments and one Goodharted gate before learning this.

### 5. DOUBLE-DERIVE — reach the answer by a second independent route
Derive the answer again from a different decomposition (columns instead of rows; the
distractors instead of the pattern; the inverse direction). Agreement is evidence;
disagreement means back to the reel — one of the two routes read a cell wrong, and the
addresses tell you which.

### 6. KILL — state the falsifiable criterion, then run it against EVERY address
Before committing: "this answer is wrong if ___." Then check the candidate against **all**
cells, not most — the rule that fits 8 of 9 cells is a different rule
(class-green ≠ instance-correct: a pattern can be green on the class of cells you tested
and wrong on the instance in front of you). Only after the full-set check does the answer
ship.

## TWO CROSS-CUTTING LAWS

- **VIRTUALIZE** — run the work inside a frame the model already carries dense priors for
  (a table, a coordinate grid, algebra, a filesystem, a film set). The reel IS
  virtualization of attention: comprehension in the source system arrived when the work
  became "a roleplay that does work," not a novel abstraction. If the problem keeps
  slipping, the representation is the bug — re-reel it into a denser world.
- **AREA** — an observation too small to register does not register (the source arithmetic:
  a 6px accent on a 200px cell reads as nothing). The critical detail must be brought to
  full size — quoted, expanded, isolated on its own line — before it can drive a decision.

## THE COMPOSE — one worked shape (matrix item)

1. REEL: cells (1,1)…(3,3) listed, each with its literal contents.
2. SWEEP: every cell once → note shape / count / shading / orientation per cell.
3. DRILL: features per cell into a table (three feature columns beat one "gestalt").
4. MEASURE: per-feature deltas across rows AND columns; each candidate rule stated as
   arithmetic, checked against every cell it claims to govern.
5. DOUBLE-DERIVE: predict (3,3) from row rule and column rule separately; also eliminate
   answer options against the measured features (the second route).
6. KILL: "wrong if any cell violates the rule" — run all 8 known cells + the prediction;
   only a 9/9 fit ships.

## NOT

- answer from the glance (the fluent first completion is the trap, not the ability)
- drill a guessed location without the sweep · stop at the sweep and report
- conclude below resolution — "probably X" about a detail you did not expand
- use an impression a measurement could replace
- accept a rule checked against SOME cells
- trust a self-made check without asking "can it pass while I'm wrong?"
- ship a single derivation of anything that mattered

## TRIGGER

Any bounded hard-reasoning item (puzzle, test item, riddle, pattern, subtle bug, tricky
spec question) · any moment an answer feels ready before the object was exhaustively
read · any "probably / seems / looks like" about a detail that has an address · being
told to pay attention.
