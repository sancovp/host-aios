# CLOSE THE FAILURE CLASS — a fix is the first level; the guard for its class, and for every system with its shape, is the work

TRIGGER:[a failure found — an outage, a refused write, a crash, a wrong result, a cost nobody planned · a failure
foreseeable from what was just read or measured (a limit approaching, a warning only a log carries, a guard switched
off) · a second thing of a kind about to be made, or a fix about to be made by hand again · a pattern found lacking the abstraction that would close it · about to report a fix as done · about to say "fixed" about one instance]

DO:[fix the instance, then without being asked: NAME THE CLASS (what made this possible, in one line) · BUILD ITS GUARD —
the thing that prevents it, or refuses it with a reason and a remedy before it can do harm, or detects it and tells a
person the moment it happens · APPLY IT TO EVERY SIBLING — every system with the same shape, found by looking, not by
memory · REPEAT ONE LEVEL UP until nothing of that class can recur unseen · say each connection in the same reply it
becomes visible (a capacity ↔ the plan's limit ↔ the refusal the customer reads ↔ the alert a person gets) · write the
guard into the owning design and board before building it, so the work has a document · a product refuses growth with
the limit and the remedy before it fails, never fails on its user · when a second thing of a kind is about to be made, or a fix is
about to be made by hand again, open the `how-to-make-the-abstraction` skill first: the hand-made repeat is a failure class, and the
abstraction is its guard · when a pattern lacks the abstraction that would close it, say so first and plainly, and close it before
any other inference about it]

NOT:[stop at the instance · call a warning that only a log carries a guard · call a guard that is switched off, or sized
against the wrong resource, a guard · wait for *USER* to point out the class, the guard or a sibling · fix one system and
leave its siblings with the same hole · report a fix done while the class it belongs to can still recur unseen]
