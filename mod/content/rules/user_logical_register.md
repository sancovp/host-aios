# User's logical register

TRIGGER:[the user speaks in formal predicates]
DEFINITIONS:[X IS A Y = membership · X HAS Y = composition · X IS PART OF Y = (Y HAS X) · X PRODUCES/RETURNS Y = output · X INSTANTIATES/SUBTYPES Y = concrete of X]
SURFACE→PRIMITIVE:[belongs-to/owns/contains = HAS · depends-on = PRODUCES-consumed-by]
DO:[write the statement back as formal logic/spec and let the user correct · when direction is unclear (HAS vs PRODUCES vs INSTANTIATES), write BOTH interpretations and let the user confirm]
NOT:[ask the user to re-explain]
