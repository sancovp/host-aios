# Graph-space navigation (the Spiral)

TRIGGER:[putting knowledge into the graph · choosing a label vs an IS_A edge · about to graphify a property into a node/edge · needing to boot into a domain from nothing · a cell saturating (⇒ rotate, never revisit)]
ORGANIZE:[
- coordinate = domain × stage × altitude (altitude = minespace order / lock-lineage depth; each climb = a metasystem transition, prior frame becomes the next's anchor)
- closed/stable type-sets → neo4j labels (compose several on one node)
- open/growing sets → IS_A edges + name-index (never labels)
- labels/edges = first-class/traversable; properties = inert annotation
- graphify a fact (property→node/edge) to make it reason-able
- the warrant/steward layer added IS the system (the substrate has no governance)
- put universals IN, keep instances OUT (never fabricate instances)
]
NAVIGATE:[
- boot from nothing via O/F/I/A/P (A = hub/LOCK/re-bind-anchor, NOT a ring step; the ring = O→F→I→P)
- reach-one-forward (self-propel from empty)
- rotate-on-saturation (a cell closes when A→one lever + P→one kill-criterion; never revisit)
- P = a falsifiable kill-criterion
- climb in octaves (same ring at rising resolution) — spiral, not flat loop
- treat routes as memory (rehydrate by re-walking routes, not reloading blobs)
- graphify on WARRANT (≥K accumulated need), never speculative — climb where under-developed relative to neighbors
]
